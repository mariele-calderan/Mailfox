# MailFox

Uma caixinha digital gratuita para enviar recados, músicas, memórias e pequenas surpresas aos amigos.

O MailFox não usa cadastro nem banco de dados. Todo o conteúdo da entrega fica codificado no próprio link compartilhado. Por isso, evite colocar informações sensíveis e use links públicos para fotos, músicas e vídeos.

## Publicar gratuitamente no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. Nas configurações do repositório, abra **Pages**.
3. Em **Build and deployment**, escolha **GitHub Actions**.
4. Aguarde a ação “Publicar MailFox” terminar; o endereço aparecerá na própria página.

## Rodar no computador

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
